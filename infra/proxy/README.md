# infra/proxy

**PLACEHOLDER — owned by WS0.2.**

This directory will hold the reverse proxy + forward-auth service (e.g. Caddy or
Traefik, with TLS) that fronts the platform. It is intentionally **not** part of
`docker-compose.yml` yet; the compose file leaves a documented seam for it.

Nothing here should be implemented until WS0.2.
